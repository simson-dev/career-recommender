# career-recommender# 🎓 Career & Degree Recommendation System

A web-based Career & Degree Recommendation System designed to help 12th-standard students identify suitable career fields and degree courses based on their interests.

## 📌 Project Description

Choosing the right career and degree after 12th standard can be difficult for many students.

This project provides a simple career guidance system where students can answer interest-based questions. The system analyzes their answers using a scoring mechanism and recommends a suitable career category along with related degree courses.

   ↓

   ↓

   ↓

   ↓

   ↓

## 📊 Interest Scoring

Each question has five interest levels:

- Not Interested = 0
- Little Interested = 1
- Interested = 2
- Very Interested = 3
- Highly Interested = 4

The system calculates scores for different career categories based on the student's answers.
